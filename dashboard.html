Evolution equation
dC/dt  =  kappa*C  +  C*kappaT  −  Omega(C, kappa)
The DeePN2 neural network learns the closure term Omega(C, kappa) from Brownian dynamics simulation data. Input features use rotationally invariant tensor invariants I1=tr(C), I2=det(C), I3=tr(C^2) to enforce frame indifference.
